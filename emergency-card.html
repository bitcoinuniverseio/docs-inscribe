Inscribe emergency recovery card

Print this and keep it with your encrypted recovery kit. One page, no secrets: never write a seed phrase or key on this card.

The rules that never bend

  1. Never pay twice on a hunch. Absence of detection is not absence of payment.
  2. Top up the exact displayed difference. Never repeat the full quote.
  3. A confirmed Bitcoin transaction is final for everyone.
  4. Never publish or share a recovery kit, seed phrase, or key.
  5. Never act while the live status page reports a source stale or down.

If a payment is missing or stuck

  1. Save the payment transaction id from your wallet.
  2. Reload the order page after one confirmation window.
  3. Stuck? Fee-bump with replace-by-fee if the wallet allows, otherwise wait.

If the order is lost

  1. Check the in-app browser order list first.
  2. Restore the order URL from the encrypted recovery kit file on your disk.

Evidence to keep for support

Order URL, payment transaction id, quoted amount, paid amount, screenshots. None of it is secret.
